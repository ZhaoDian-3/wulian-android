# 五练 1.1.0

Android 8.0+。使用原发行签名，可覆盖安装 1.0.0，保留本机数据。

Actions → Download signed APK → 最近成功运行 → Artifacts → wulian-1.1.0-apk。下载 ZIP 后解压安装 APK，需要登录 GitHub。

训练页点击「编辑动作」或下方注释，可修改动作名称、分类及多行注释。默认同步修改计划以用于后续新建训练，也可取消勾选仅改本次。历史记录编辑仅影响所选记录。重量、次数、组数和完成状态保留。计划页也可以编辑动作和注释。

此流程验证并分发已签名发行包，不重新编译。私钥不存放在仓库。

验证：Java 编译、APK 签名与升级签名一致性、动作编辑数据回归测试。未完成安卓真机界面验收。
